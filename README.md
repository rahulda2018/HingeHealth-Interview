# HingeHealth-Interview

To ensure we can jump straight into the coding exercise during your interview, please complete the setup process ahead of time by following these steps:

-- Within 48 hours from submitting your Github username, you’ll receive an email from Github Hinge Health “Accept Your Repository Invitation”

-- Check your email for an invitation from GitHub to access your dedicated interview repository, and click the link to accept access.

-- Follow the step-by-step instructions in the repository's README.md file to configure your local setup.
